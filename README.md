# @a-dev

This repository is a collection of experiments and probes in web development, design, and technology. Each probe explores a specific concept, technique, or feature in depth, with practical examples and key takeaways.

## Probes

- [Overscroll Behavior: Rubber Banding](src/pages/overscroll/index.astro): Explores overscroll behavior in web browsers, especially the "rubber banding" effect on touch devices. It compares browser implementations and shows how CSS can customize or disable the behavior.
